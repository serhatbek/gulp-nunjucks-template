# 📁 Adding Assets (Images & Fonts)

Some assets in your project, like images and fonts, need to be **manually added** to your build folder because they are not automatically generated by Gulp tasks.

## 🖼 Images

- Place all images used in your project here:

```bash
dist/assets/images/
```

- Examples:

```bash
dist/assets/images/logo.png
dist/assets/images/background.jpg
```

- These images can then be used in your HTML, CSS, or templates:

```html
<img src="../assets/images/logo.png" alt="Logo" />
```

## 🔤 Fonts

- Place all font files here:

```bash
dist/assets/fonts/
```

- Supported font types: `.ttf`, `.woff`, `.woff2`, `.eot`, `.svg`
- Example structure:

```bash
dist/assets/fonts/Roboto-Regular.woff2
dist/assets/fonts/icons/
```

- Icons inside `dist/assets/fonts/icons/` are generated automatically via the **Icon Font** task, but any additional custom fonts need to be manually added.

## ⚠️ Important Notes

> These folders preserve images and fonts that's why when cleaning the build (`cleanBuildDirectory` task preserves images and fonts).

> Always make sure the path in your HTML/CSS matches the folder structure.
